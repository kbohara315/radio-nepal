# Agent notes

- Read `SPEC.md` and `src/types.ts` before changing anything.
- Before using ui-sdk, read `node_modules/@ui-sdk/react/docs/llms.txt`. To build a new component,
  also search `node_modules/@ui-sdk/react/docs/core.md` by heading, and read `rendering.md` next
  to it. Component pages are in `node_modules/@ui-sdk/react/docs/components/`.
- Package manager: pnpm. Type check: `pnpm exec tsc -b`. Build: `pnpm build`.
